# v1.3.6 —— 整合包 2.0：可切换、可维护、可分享的场景配置

## 新增

- **应用此整合包（场景切换）**：整合包详情页的「应用此整合包」按每个成员的目标启停精确恢复整套配置；旁边的「同时关闭本包以外的 Mod」（默认关）可把别的场景残留的替换一并关掉。从「射击包」切到「近战包」不再互相覆盖。一次写入 `addonlist.txt`，不逐个卡顿。
- **启停快照**：建包 / 导入时可「保存当前启停状态」；详情页「从当前启停状态更新本包」一键记录，之后切回该场景即精确还原。
- **整合包 ZIP 导入**：工具栏「导入整合包」选 `.zip` 即可导入——按导出时写入的 `_name_map.json` 还原原文件名、复用拖放导入的判重与封面逻辑落盘并自动建包。此前只能导出不能导入，现在「导出 → 分享 → 导入」成为闭环。已拒绝 zip-slip / 符号链接 / 超大解压。
- **失效成员可见与清理**：包卡片与详情显示「失效 N」，一键清理磁盘上已不存在的成员。
- **包卡片信息增强**：`启用 X/Y`、`⚠ 冲突 N`、`⚠ 失效 N` 徽标 + 描述一行。

## 改进

- 「应用此整合包」与「全部启用 / 全部禁用」拆成两级：前者按快照精确切换场景，后者只是快捷整包开关。
- 整合包更新（改名 / 替换成员 / 快照 / 描述 / 封面）合并为一次原子写盘，不留半截状态。
- 数据模型只加键、不改 `data.json` 结构版本、不写迁移；旧版本回滚读到新键也不会崩。

## 已知取舍

- 整合包封面目前默认沿用「最后一个仍存在的成员」，数据层已支持指定封面（`cover_mod`），但设置封面的入口暂未在界面暴露。
- ZIP 导入的 VPK 落盘沿用现有拖放导入的规则：同名不同内容不覆盖、同内容重复跳过并报告。

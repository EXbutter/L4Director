# v1.3.3

创意工坊详情补上多图预览与依赖清单，下载拆成「直接下载 / 加入队列」；「我的 Mod」新增同步 Steam 订阅与一键补全 Addonlist。

## 新增

- **工坊详情多图预览**：抽屉打开时拉取完整详情，主图下多一条横向缩略条，点击切换。
- **工坊详情直接看依赖**：放在描述之前，每项显示缩略图、标题、大小、状态，没装的可直接下载。装漏前置时主 Mod 往往「看着能用、实际少东西」。
- **同步 Steam 订阅**（我的 Mod）：读取 Steam 账号订阅，和本地对账 —— 订阅了但本地没有的进下载队列，本地有但已取消订阅的可一键删除。
- **一键补全 Addonlist**（我的 Mod）：把本地有 VPK、但 `addonlist.txt` 里没有条目的 Mod 一次补齐（这类包在游戏「附加内容」里看不到）。只补缺失，已有条目不动。
- **自定义标签**：自建标签池，右键给 Mod 打标签、按标签筛选，删除标签时从所有 Mod 一并摘掉。

## 改进

- **下载拆成两个入口**：「直接下载」（入队并立刻开始）与「加入队列」（稍后到下载页统一开始）。已入队的条目按钮自动联动成「开始下载 / 已在队列」。
- **标题栏 logo 换成字标**：去掉方块图标，改为「L4D 大 + irector 小」的矢量字标（SVG path），任何机器渲染一致。

## 修复

- **工坊多图预览每张都一样**：缩略图缓存键只按 Mod ID 冲突、本地封面无条件优先、浏览器缓存旧响应，三处叠加所致。现在按「ID + 图片地址」缓存，图集各图独立。
- **订阅对账只信国际站**：中国区端点对订阅接口返回空数组且不报错，会误判「一个订阅都没有」并把本地文件全删。现优先国际站。
- **详情抽屉长描述被截断**：flex 子项缺 `min-height: 0` 导致滚动失效。现在中段滚动，描述能滚到底。

## 升级

覆盖安装即可，合辑 / 标签 / 显示名全部保留。仅支持 Windows。

发版需上传三个附件（文件名须与 `latest.yml` 的 `url` 一致）：

```
L4Director-Setup-1.3.3.exe
L4Director-Setup-1.3.3.exe.blockmap
latest.yml
```

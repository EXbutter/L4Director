# v1.3.2

「我的 Mod」开始认识包里的具体内容：每个包替换了清单里的哪些角色 / 武器，可以按成员随机拼一套组合，页面上常驻显示当前组合的完整度。创意工坊卡片把好评率换成好评数 + 累计下载量。

## 新增

- **成员级识别**：卡片标签行前面多一个标记 —— `生还者 3/8`、`特感 8/8`（整套换完显示为绿色）、`武器 2/35`。悬浮能看到具体换了谁。判定靠 VPK 里的文件路径认人（`survivor_namvet.mdl` = 比尔），不是看标题猜。
- **一键混搭（按成员随机）**：每个角色、每把枪单独随机挑一个替换包，8 个生还者各挑一个；同一成员只会有一个包提供，挑包时自动排除已被占用的成员。合集包也能参与，被挑中时它覆盖的那批成员整片落地。面板里能勾选参与混搭的类别、能「换一批」重滚，每行显示「N 选 1」。
- **当前搭配完整度看板**：常驻在筛选栏下方，`生还者 8/8 · 特感 6/8 · 物品 0/4 · 武器 18/35`，展开后逐个成员列出 —— 彩色 = 已有包在换它，虚框 = 还是原版。右侧「补齐缺口」直接带着缺口类别进混搭面板。
- **「整套替换」筛选**：只留下把某一类整个换完的包。

## 改进

- **好评率 → 好评数 + 下载量**：封面、列表行、详情抽屉三处统一改成 `赞 19 · ↓ 53`。原来的百分比几乎全挤在 50~60 之间，既分不出好坏，也看不出几个人投过票。好评率本身挪进了悬浮提示。
- **下载量取累计订阅人数**（含后来退订的）—— 工坊没有真正的下载计数字段，这是唯一能量出基数的那个；当前订阅数单独显示。缺数据就不渲染那一项，不写 0。
- 批量启停「其实一个都没改动」时不再点亮左下角的「应用」。
- **成员名统一用官方英文名**：`Zoey`、`Tank`、`Hunting Rifle`，不再翻成「佐伊 / 坦克 / 猎枪」；中文译名挪进悬浮提示。

## 修复

- **界面版本号只显示到「主.次」**：侧边栏和「设置 → 关于」以前是 `v1.3`，安装包文件名和更新提示却是三段，容易被读成「装的是旧版」。现在统一显示完整版本号。
- **复选框是浏览器默认方块**：全站统一成 14px 圆角小方框，选中是主色填充 + 白色对勾，深色 / 浅色主题都跟随主色。
- **筛选栏右侧的按钮看不出来是按钮**：`一键混搭` 变成主色实心按钮，`检查更新` 改成扁平描边按钮，统计数字移到这组最左边。

## 安全

`frontend/public/` 下的文件会被 vite 原样复制进安装包（`app.asar` 内一份、`resources\public\` 一份明文）。已去掉那条 `extraResources` 配置，并在校验脚本里加了断言 —— `public/` 下出现任何图片都算校验失败。

## 升级

覆盖安装即可，合辑 / 自定义名称 / 标签全部保留。升级后第一次扫描会重算全部 VPK 的覆盖信息，比平时慢一些，之后照旧走缓存。仅支持 Windows。

发版需上传三个附件（文件名须与 `latest.yml` 的 `url` 一致）：

```
L4Director-Setup-1.3.2.exe
L4Director-Setup-1.3.2.exe.blockmap
latest.yml
```

# v1.3.1 — 创意工坊变成自己的 Mod 浏览器

创意工坊以前是内嵌 Steam 网页。国内要开加速器才打得开，筛选器只有 6 个分类，
封面还是几十 MB 的 GIF。这一版把它换成了软件自己的浏览器：**有筛选、有两种排版、
有详情抽屉、能直接加入下载队列**，零配置也能用。

---

## 亮点

**1. 筛选真的能用**

关键词（中文也行）+ **50 个真实标签**，按类型 / 角色 / 特感 / 武器 / 模式分组，
支持「同时满足」和「命中其一」，再加时间范围与「只看未下载」。标签词表是从 600 条
样本里统计出来的 —— Steam 网页筛选器只暴露 6 个分类和角色、特感，差得远。

**2. 两种排版，各记各的**

- **卡片墙**：16:10 封面，默认窗口每行 4 张，看封面挑东西。
- **单列列表**：96×60 缩略图 + 标题/简介/标签 + 右侧订阅数、体积、更新时间，
  一屏 7~8 行，按数据扫。

顶栏一键切换，选择会被记住，两个页面的密度偏好互不影响。

**3. 不用申请任何 key**

- **默认**：抓工坊浏览页拿 ID，大小、时间、订阅、标签、封面一律回源到免 key 的
  官方接口 —— 每页 30 条，开箱即用。
- **可选**：设置里填 Steam Web API Key 后走官方 `QueryFiles`，每页 100 条、
  带好评率和精确总数、支持深翻页，国内端点实测 100 条约 1.0 秒。

不填 key 一切照常，只是每页 30 条；填了随时能清掉，后端只回传掩码
（形如 `A1B2…9F0E`），从不回传原文。

**4. 详情抽屉 + 一键入队**

大图、大小 / 订阅 / 浏览 / 更新时间 / 好评率、清洗过的描述（BBCode 和裸图片直链会被
清掉）、标签，底部直接「加入下载队列」，复用既有的下载器。

## 性能：整页从 16 FPS 修回 200 FPS

第一版卡片是裸 `<img>` 直接指向封面地址，上线后整页只有 **16 FPS**。查下来不是布局
也不是动画 —— 是封面素材本身：工坊里混着一批 GIF 动图，实测单张最大 **28 MB**，
缓存里 66 个动图共 **405 MB**。Chromium 会把动图全部帧解码常驻，一屏十几张就把主线程
压满了。

- 封面改走项目里已有的 `ThumbImage`：只解第一帧、按卡片尺寸降采样后重编码成 WebP；
  **动图只在鼠标悬停时**才逐帧解码，一次只有一张。
- 卡片进入视口附近才开始抓图和转码，全局转码并发上限 4 —— 100 张同时开跑时
  反而掉到 2 FPS（`canvas.toBlob` 压在主线程），这两道闸门是必须的。
- 封面缓存单张超 4 MB 不落盘，总量超 256 MB 按最久未访问回收：
  实测跑几趟后从 **507 MB → 249 MB**。

现在一页 100 张卡片滚到哪加载到哪，稳定 **195~200 FPS**；详情抽屉单张动图也是 200。

## 界面动效对齐全站

工坊页是新写的，第一版是「整块啪一下出现」。这一版参数直接对齐项目既有约定：

- 顶栏 0ms、筛选栏 45ms，0.4 秒从左侧 20px 推入，和整页滑进来叠成同一股力。
- 卡片 0.3 秒、下移 16px 并缩到 0.95 起步，每张晚 24ms，一屏像水波铺开；
  列表行是左侧 16px、每行晚 18ms。
- 筛选组展开改成**高度插值**（`grid-template-rows: 0fr → 1fr`），展开和收起双向都有
  过渡。之前是条件渲染 + 内部淡入 —— DOM 一挂载就占满高度，观感是「啪」一下弹开，
  收起更是瞬间消失。
- 详情抽屉从 0.17 秒改成 0.26 秒、右侧 34px 推进，遮罩单独淡入。

所有动画只动 `opacity` / `transform`；第 25 张（行）起不播动画，避免给几十个视口外的
元素各建一个合成层。系统开「减少动画效果」时自动压到一帧完成。

## 顺带并入的数据安全维护

这一版同时包含原 v1.3.0 的维护内容 —— 都是「出错必须说出口，用户看不见的数据绝不能丢」：

- **`data.json` 读不出来时进入只读模式**，不再被默认值覆盖后写回。以前遇到文件被占用
  或权限不足，下一次改标签就会拿空默认值把原文件 replace 掉 —— 合辑、自定义名称、
  标签一起没。
- **写盘失败不再「内存改了、磁盘没改」**，并新增 `data.json.bak`：每次写盘前留上一版。
- **`addonlist.txt` 写失败如实报错**（原来接口照样回「已应用 N 项」），这是
  「软件里禁用了、进游戏还在加载」的头号根因。
- **缩略图接口堵掉路径穿越**：`?path=` 和 `wid=../` 都限定在 addons / 缓存 / 下载目录内，
  且只接受图片扩展名。
- **解析失败的 VPK 不再从列表消失**：文件保留记录，列表下方一条常驻提示逐个列出
  「文件名 + 大小 + 失败原因」并给出处理办法，附「打开所在目录」和「删除文件」。
- **「检查更新」不再看加速器脸色**：先走国内端点（实测 0.38 秒），失败再退回国际站，
  成功过的端点记 10 分钟。55 个工坊 Mod 整轮 **2.6 秒**。
- 本地纯数字文件名不再被误当成工坊 ID 覆盖掉；`store.error` 有 14 个写入点、0 个读取点
  的问题也一并接上界面提示。

## Steam API Key 改为加密存储

上一版的 key 是**明文**写在 `~/.l4d2-manager/config.json` 里的。它能被任何读文件的
程序拿到，也会跟着云同步盘、备份目录、排障时贴出去的配置文件一起走。Steam Web API Key
是账号级凭证，可以被刷配额、被判滥用，泄漏了用户还不会察觉 —— 所以这一版把它换掉了：

| | 改前 | 改后 |
|---|---|---|
| `config.json` 里长什么样 | `"steam_api_key": "60BA…"` | `"steam_api_key_enc": "dpapi:v1:AQAAAN…"` |
| 别人拿到这个文件 | 直接能用 | 解不开（密文绑定当前 Windows 账户） |
| 换 Windows 账户 / 换机器 | 照常可用 | 提示「解不开，请重填」，不会假装你没填过 |
| 完全不想落盘 | 没有这条路 | 设 `L4DIRECTOR_STEAM_KEY` 环境变量即可 |

旧版本留下的明文会在首次读取时**自动迁移**成密文，并把明文字段删掉 —— 升级不需要
你做任何事，也不用重新粘贴 key。错误信息、日志里的 key 形态字符串现在统一打码，
界面只显示首尾各 4 位指纹（如 `60BA…749E`）。

## 安装

下载 `L4Director-Setup-1.3.1.exe` 直接安装，或在旧版本上自动更新（客户端先读
`latest.yml`）。仅支持 Windows。

从 1.2.0 升级不需要手动处理任何数据：`data.json` 会自动补上 `.bak`，
现有合辑、自定义名称、标签全部保留。Steam API Key 是可选项，不填不影响任何功能。

## 已知限制

- 不填 key 时「最近更新」排序是**置灰并写明原因**的，不会悄悄降级成别的排序。
- 不填 key 时每页 30 条，翻页比有 key 时慢一些。
- 工坊条目的描述来自 Steam，清洗掉 BBCode 后仍有少量排版差异，属正常。

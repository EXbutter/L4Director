# v1.3.1

创意工坊从内嵌 Steam 网页换成软件自己的 Mod 浏览器：可筛选、可排序、有详情抽屉、能直接加入下载队列。不填任何 key 也能用。

## 新增

- **筛选**：关键词（中文可用）+ 45 个标签（类型 / 角色 / 特感 / 武器 / 模式）+ 时间范围 + 只看未下载，支持「同时满足 / 命中其一」。
- **排序**：趋势、最新发布、最近更新、评分最高、订阅最多。无 key 时「最近更新」置灰并写明原因。
- **两种排版**：卡片墙（每行 4 张）/ 单列列表（缩略图 + 体积、订阅、更新时间），顶栏切换并记住选择。
- **详情抽屉**：大图、体积 / 订阅 / 浏览 / 更新时间 / 好评率、描述、标签，底部「加入下载队列」。
- **两条数据源**：默认抓工坊浏览页，30 条/页、零配置；设置里填 Steam Web API Key 后走官方接口，100 条/页、带好评率、支持深翻页。

## 修复与改进

- 工坊页 **16 FPS → 200 FPS**：封面只解首帧、动图仅悬停播放、惰性转码（并发 4）、缓存 256MB 上限按 LRU 回收。
- 筛选组展开补上高度过渡，卡片 / 列表行错峰入场，参数与其它页面一致。
- `_save_config()` 整体重写导致已填的 API Key 在启动时被抹掉（现象：重启又要重填）。
- 并入原 v1.3.0 的数据安全维护：`data.json` 读失败转只读并新增 `.bak`、`addonlist.txt` 写失败如实报错、缩略图接口杜绝路径穿越、损坏的 VPK 不再从列表消失。

## 安全

- **Steam API Key 改为 Windows DPAPI 加密存储**，`config.json` 里只剩 `dpapi:v1:…` 密文，换账户或换机器解不开会提示重填；旧明文首次读取自动迁移并删除。
- 完全不想落盘可设 `L4DIRECTOR_STEAM_KEY` 环境变量。错误信息与日志统一脱敏，界面只显示首尾各 4 位指纹。

## 升级

覆盖安装即可，合辑 / 自定义名称 / 标签全部保留。仅支持 Windows。

发版需上传三个附件（文件名须与 `latest.yml` 的 `url` 一致）：

```
L4Director-Setup-1.3.1.exe
L4Director-Setup-1.3.1.exe.blockmap
latest.yml
```
